locale.en: |
  **Available commands**

  Built-in commands:
  - `/clear` — Clear this session's conversation history and start fresh (files, mounts and settings are kept)
  - `/compact` — Manually compact session context (LLM-summarizes old messages to free tokens)
  - `/dev-swap` — Developer hot-swap: rebuild the runtime bundle and restart onto it (tests → build → preflight → swap → verify, auto-rollback on failure)
  - `/fork` — Copy this IM (DingTalk/WeCom) conversation into a fresh desktop session (history carried over, this chat untouched)
  - `/goal` — Set or show a long-running goal for this session (advances autonomously)
  - `/help` — List available commands and skills
  - `/mount` — Mount a local folder as session context (/mount <path> [ro|rw])
  - `/mounts` — Show this session's mounted context folders
  - `/plan` — Task plans (/plan list; /plan confirm|cancel <id>)
  - `/primary` — Set the primary working directory (bash cwd); /primary clear to unset
  - `/subagent` — Create a subagent (/subagent <goal> direct; /subagent split <task> to decompose first)
  - `/subagent-split` — Split a task into multiple subagents (/subagent-split <task>, alias of /subagent split)
  - `/think` — Set or show this session's thinking effort (/think <off|low|medium|high|auto>)
  - `/umount` — Unmount a context folder (/umount <name|path>)
  - `/workflow-cancel` — Cancel the latest (or a given) workflow run
  - `/workflow-delete` — Delete a workflow definition (/workflow-delete <name|id>; run history is kept)
  - `/workflow-list` — List workflow definitions (name · version · steps · last run)
  - `/workflow-pause` — Pause the latest (or a given) running workflow run
  - `/workflow-resume` — Resume a paused workflow run (human answers still go via the Workflows page)
  - `/workflow-run` — Start a workflow run (/workflow-run <name|id>, fuzzy name match)
  - `/workflow-status` — Show the status of the latest (or a given) workflow run

  Skills (invoke with `/skill-name [prompt]`):
  - `/browser` — 操作用户的 Chrome 浏览器（打开/切换标签页、点击、输入、截图、读页面、跑 JS、抓网络请求）。Use when the user asks to browse/open/scrape/automate a web page.
  - `/todo` — 快速管理用户的每日 TODO 清单（增删改查、完成、关联产物）。Use when the user wants to add/list/edit/complete/delete TODO items.
