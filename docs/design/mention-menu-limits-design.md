# @ Mention 菜单减负：分组限量 + 输入过滤增强 产品方案

> 状态：设计稿（未实施）。原型：`design-mocks/mention-menu-prototype.html`
>（可交互——模拟输入过滤 / 组折叠 / 展开动画 / 键盘导航）。

## 0. 问题

当前 `@` 菜单（ComposerMenu.tsx 平铺渲染 + commandMenu.ts contains 过滤）：

- **空查询全量**：敲 `@` 时 query 为空、matches() 全中——sessions/artifacts/results
  几十条一次性铺满屏幕，遮挡聊天上下文；
- **无每组/总量上限**：长列表滚动找目标的成本高；
- **无动效**：弹/关/过滤瞬间跳变，视觉噪音；
- 过滤本身已有（name/desc contains），痛点在「初始面」与「结构」。

## 1. 设计原则

1. **首屏给方向，不给全部**：`@` 空查询时每组只给 top 10，方向对了再继续收窄；
2. **输入即过滤（强化）**：保留 contains，补匹配片段高亮；query 非空时组内
   匹配项置顶、无匹配组整组隐藏（不留空组头）；
3. **超出可发现、可展开**：被折叠的数量可见（「还有 18 个」），点击/Enter
   展开该组，展开态记忆到本次触发会话；
4. **动效服务信息层级**：弹出/收起/过滤/展开四类过渡 ≤180ms，不做装饰性动画。

## 2. 分层限量规则

| 层 | 规则 |
|---|---|
| 菜单范围 | **仅 mention 四类**：agents / sessions / artifacts / results——与现状一致
（`/` 触发的 commands+skills 是另一套菜单，本方案不改动它的行为；其限量可作 P2 同构复用） |
| 每组上限 | **10 条**（空查询与有查询同规则；展开后该组免限） |
| 总量软上限 | 全部可见组合计 ≤ 28 行（约视口高度的菜单主体），超出时低优先级组整体折叠为「组头 + 计数」一行 |
| 组优先级 | agents > sessions > artifacts > results（高优先组先占预算；可按遥测调整） |
| 组内排序 | 最近使用优先（sessions 按最后活跃 / artifacts 按 mtime / agents 按最近协作），无数据时字典序 |
| 折叠指示 | 组头右侧灰字计数 `3/28`；被截断的组尾行「还有 18 个 · 继续输入或 ↵ 展示全部」 |
| 空查询的引导 | 菜单顶部一行 ghost 提示：「输入关键词过滤 · ↑↓ 选择 · ↵ 插入 · kind: 前缀定向（@art/@agent/sess/res）」 |

## 3. 过滤增强

- **匹配高亮**：query 命中片段黄底标记（name 与 desc 都标）；
- **无匹配组隐藏**：组内 0 命中即整组不渲染（比保留空组头更干净）；
- **全空态**：所有组 0 命中 → 单行「没有匹配 “xx”——清词或 Esc」；
- P2（不做本次）：拼音首字母匹配、fuzzy 打分排序。

## 4. 动效规格（原型已实现，可直接照抄参数）

| 动作 | 参数 |
|---|---|
| 弹出 | opacity 0→1 + translateY(6px→0)，160ms cubic-bezier(.2,.8,.3,1)； origin top |
| 收起 | 反向 120ms（不占位即退场，不留残影） |
| 过滤引起的高度变化 | 菜单容器 `interpolate-size: allow-keywords` / max-height 过渡 180ms（Safari 17.4+ 用 FLIP 兜底） |
| 列表项增删 | 新项 fade-in 120ms；移除项不动画（瞬时，避免闪烁） |
| 「显示全部」展开 | 组容器 grid-template-rows 0fr→1fr 过渡 180ms |
| 键盘选中态 | 高亮背景跟随（现有 scrollIntoView nearest 保留），无独立动画 |
| 组头 | sticky 置顶（长组滚动时分组名始终可见） |

## 5. 交互细节

- **展开态记忆**：同一次 @ 触发会话内记住用户展开过的组；重新触发 @ 复位；
- **Enter 语义优先级**：高亮项为「显示全部」行时 Enter=展开该组（不插入）；
  其余项 Enter=插入；
- **Tab**：展开/收起高亮项所在组（与 Enter 区分）；
- **鼠标**：hover 高亮与键盘高亮共用同一状态（避免双高亮）；
- **超长菜单**：菜单主体 max-height 60vh，内部滚动；组头 sticky。

## 6. 实施拆分（估）

1. `commandMenu.ts`：组内排序（最近使用）+ 每组 slice(0,10) + 组计数元数据
   （纯逻辑，可单测：限量/排序/无匹配组隐藏/全空态判定）；
2. `ComposerMenu.tsx`：组尾「还有 N 个」行 + 展开动画（grid-rows）+ 匹配高亮
   `<mark>` + ghost 提示行 + 弹出动效（menu 容器挂载/卸载 class）；
3. Composer 侧：展开态 useState（触发会话级）+ Tab 键处理；
4. 测试：commandMenu 纯函数单测矩阵；vitest 组件级不覆盖（无 DOM 环境，维持现状）。

预期改动面：2 个现有文件 + 1 处 Composer 接线，≈1 PR。
