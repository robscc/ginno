2

总结 session → workflow（v1）

POST /api/workflows/summarize-from-session · 返回 DSL 草稿并创建 v1
⌁ 生成的 DSL（识别出 loop + branch）
{ "name": "Trending Repo 分析", "entry": "fetch", "nodes": [ { "id":"fetch", "type":"step", "goal":"拉取 GitHub Trending 列表" }, { "id":"loop", "type":"loop", "over":"context.repos", "as":"repo", "body":"analyze", "max_iters":5 }, { "id":"analyze","type":"step", "goal":"分析 {{repo}} 并写分析报告" }, { "id":"gate", "type":"branch", "cases":[{ "when":"len(context.reports)>0", "then":"notify" }], "default":"done" }, { "id":"notify", "type":"llm", "prompt":"汇总 {{n}} 份报告" }, { "id":"done", "type":"pass" } ], "edges": [ {"from":"fetch","to":"loop"}, {"from":"loop","to":"gate"} ] }
把"对每个 repo 分析"识别为 loop；"有报告则汇总"识别为 branch；loop→gate 为串联续跑边。
