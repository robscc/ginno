连接器统一基座 · 差异化外观（原型）

原则：统一的是基座，不是样式。状态机、配置下发、授权、install steps、apply_config 共用一套；每个连接器（内置或 Claude Mod）自己声明有哪些 tab、哪些区块、哪种布局。

看差异：Chrome 有「安装向导 / 连接状态」；钉钉有「会话策略」；Vibe Island 很轻，只有设置和活动； Claude Mod 有「概览 / 设置 / 权限 / 活动」。点任意卡片打开侧滑详情——同一套抽屉外壳，内容按连接器声明生成。
